# Formation Playwright

Projet d'apprentissage de l'automatisation de tests avec **Playwright** et **TypeScript**.

## Objectif

Maîtriser l'automatisation de tests web de bout en bout (E2E) et d'API,
en vue de missions de QA automaticien.
